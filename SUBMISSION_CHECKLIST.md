- [ ] Project title and short description
- [ ] Three core features
- [ ] System architecture diagram (frontend -> REST API -> Azure SQL / Blob Storage)
- [ ] ER diagram (`docs/ER_DIAGRAM.md`)
- [ ] SQL schema (`database/schema.sql`)
- [ ] Threat model (`docs/THREAT_MODEL.md`)
- [ ] Backend source code (`src/`)
- [ ] API endpoint table and setup instructions (`README.md`)
- [ ] Screenshots of API tests (health, register, login, add device, report issue)
- [ ] Team member names, roll numbers and contribution details
- [ ] Limitations and future scope
- [ ] Remove `.env`, passwords, tokens and personal data before uploading
